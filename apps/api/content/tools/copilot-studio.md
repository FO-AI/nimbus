## What it is

Copilot Studio is where a custom agent gets built: you point it at a defined
set of documents — your unit's SOPs, a policy manual, an onboarding pack —
and staff ask it questions instead of hunting through SharePoint.

This is not a self-serve tool. It is a project, with a build, a review, and
an owner who keeps the source documents current. An agent answering from a
year-old policy file is worse than no agent.

## When a Copilot Studio agent is the right answer

- The same questions arrive repeatedly and the answers live in documents you
  control
- Those documents are stable enough that someone will actually maintain them
- The questions are informational, not decisions with legal or personnel
  weight

## When it is not

If you want an agent to *decide* something — route an approval, score a
vendor, assess an employee — stop. That is outside what the Staff Generative
AI Usage Guidance permits, regardless of how the agent is built.

## How to request one

Go through the [AI Acceleration Program](https://aiacceleration.unc.edu/).
If the agent will touch data from a vendor system or anything above Tier 2,
it also needs the [risk assessment path](/guides/sensitive-data) — ISO
review and Data Governance Oversight Group approval — before it goes live.
