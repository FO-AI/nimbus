## Start from a prompt, then make it yours

Every prompt in this library is a starting point, not a finished instruction.
The ones that work are the ones someone adapted to their own department, their
own data, and their own reader. This page is the campus framework for doing
that well.

## CLEAR

The University Library teaches **CLEAR**, developed by Leo S. Lo. Five things
to check before you send a prompt:

| | |
| --- | --- |
| **Concise** | One task. Cut anything that is not needed to do it. |
| **Logical** | Give the information in the order the work happens. |
| **Explicit** | Say exactly what you want. Ambiguity is where bad output comes from. |
| **Adaptive** | The first answer is a draft of the prompt, not just of the output. Adjust and re-run. |
| **Reflective** | Notice how a tool responds to different phrasings, and carry that forward. |

## What this looks like in Finance & Operations

**Concise** — "Draft a variance narrative for Travel and Supplies" beats a
paragraph of background the model does not need.

**Logical** — give the context, then the data, then the instruction. A prompt
that asks for the output before supplying the inputs tends to get a guess.

**Explicit** — name the audience and the length. "Under 200 words, for a budget
officer, plain non-defensive language" produces something usable; "write a
summary" does not.

**Adaptive** — if the output restates your numbers oddly or misses a driver,
the fix is usually one more sentence in the prompt, not a different tool.

**Reflective** — when a prompt works, save it. That is how this library grew.

## Where to find more prompts

- **This library** — [browse the prompts](/prompts), filtered by department and
  by tool. Each one carries usage notes and what to double-check.
- **Microsoft's Copilot Prompt Gallery** —
  [adoption.microsoft.com](https://adoption.microsoft.com/en-us/copilot/prompt-gallery/)
  filters by app and by function, including Finance, HR, and Operations, and
  lets you open a prompt straight into Copilot.
- **The Library's full guide** —
  [Prompt Engineering](https://guides.lib.unc.edu/GenAI/prompts) covers CLEAR
  and other frameworks in more depth, and the
  [Library AI Studio](https://library.unc.edu/ai/library-ai-studio/) runs
  workshops and one-to-one consultations.

## Before you paste

Whatever the prompt says, the data rules still apply. Check
[what data can I put into an AI tool](/guides/sensitive-data) — Tier 1 and 2 in
an approved tool, never Tier 3, and never for hiring, evaluation, or discipline.
